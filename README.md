# Bootcamp - Group-Based Chatting Application

Bootcamp is a group-based chatting application built using Flutter and Firebase. This app allows users to join and create group chats, offering a simple and efficient way to communicate in real-time across different devices.

## Features

- **Real-Time Messaging**: Send and receive messages instantly using Firebase's real-time database.
- **Group Chats**: Create and participate in multiple group conversations.
- **Cross-Platform**: Built with Flutter, the app works on both Android and iOS platforms.
- **Firebase Integration**: Secure authentication, real-time syncing, and cloud storage with Firebase.
